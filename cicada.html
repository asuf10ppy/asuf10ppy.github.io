Cicada 3301: SURE MUN

A web version of a challenge I wrote for Gene/sys

Cicada 3301 was a campus-wide cyber-investigation event at IIIT Bangalore: solve a challenge, get a key, unlock the next one. This is a small replica of my challenge. The key here is new, not the one used at the event.

the-brief

Don't trust the first thing the signal tells you, or the second, or the hundredth. It was built to repeat, and the repeating is not a mistake. Hours of broadcast, and one minute that matters.

Everyone remembers the number, and it is facing the wrong way. Some numbers in this story are real and some are bait. The only way out is through.

Key format: Cicada3301{16 hex characters}

the-signal

Download signal_mini.wav

3.2 MB. Your player will show about 79 minutes (the event version showed 79 hours). Open it in Audacity, VLC or similar. Browsers can't play it directly.

your-answer

stuck

  1. The header lies. The file says 348 Hz and about 79 minutes, so it sounds like nothing. Plot its spectrum and you will see a steady hum near 47.8 Hz.
  2. Use the number. If that hum is really 3301 Hz, the audio is slowed by 3301 / 47.84 = 69. The real sample rate is 348 x 69 = 24,012 Hz. Set the track rate to 24012 in Audacity (track menu, Rate, Other) or run the script below.
  3. Listen. The restored audio is 69 seconds long: noise, the 3301 Hz hum, and a 600 Hz Morse message that keeps repeating KEEP LOOKING. That repeating message is the bait.
  4. Face the number the right way. 3301 reversed is 1033, so look at 10.33 seconds. (The event version hid it at 10:33.) A different Morse message starts there.
  5. Decode it by ear, or with a 600 Hz band-pass and a Morse table. It spells a web address: ASUF10PPY.GITHUB.IO/SYNERGY2026
  6. Open the page. It is a 40 minute archive with captions. This time the number is real: go to 33:01 and read the key.
import wave
src = wave.open("signal_mini.wav")
dst = wave.open("restored.wav", "wb")
dst.setnchannels(1); dst.setsampwidth(2)
dst.setframerate(src.getframerate() * 69)   # 348 x 69 = 24,012 Hz
dst.writeframes(src.readframes(src.getnframes()))
dst.close()
